# Документация

## Архитектура

- [**Архитектура KIR**](ARCHITECTURE.ru.md) — компилятор по стадиям: реестр как единый источник
  истины, прямой конвейер (проверка типов → заземление → план → эмиссия → гейт Roslyn → живой
  запуск → свидетель), обратный конвейер (извлечение → перепись → лифт → фолд → материализация →
  проверка пересборкой), пять законов сохранения, версионирование.
